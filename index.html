Generator dan Scanner QR Code Online

Gunakan konverterQR Khresmupu untuk membuat QR Code dengan cepat dari teks atau link. QR Code yang dibuat dapat diunduh sebagai PNG atau dicetak menjadi PDF.

Fitur Utama

  • Membuat QR Code dari link atau teks secara instant.
  • Kustomisasi judul tempat/toko, sub-judul, dan deskripsi catatan pada kartu QR.
  • Memindai QR Code menggunakan kamera perangkat.
  • Membaca QR Code dari file gambar.
  • Fitur pemotongan (crop) area gambar sebelum diproses.
  • Mengunduh hasil dalam format PNG beresolusi tinggi.
  • Fitur cetak ramah dokumen (PDF).

Cara Menggunakan

Masukkan link atau teks pada kolom generator untuk membuat QR Code. Untuk membaca QR Code, pilih tab Scan QR lalu gunakan kamera atau unggah gambar QR Code dari galeri Anda.

Tentang konverterQR Khresmupu

konverterQR Khresmupu merupakan web tool gratis yang dirancang untuk bekerja langsung melalui browser tanpa instalasi aplikasi tambahan.
