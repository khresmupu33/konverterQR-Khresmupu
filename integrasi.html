Integrasi

Pasang Tombol QR Code di Website Anda

Tambahkan satu tombol di website Anda. Saat diklik, konverterQR Khresmupu terbuka dengan link, judul, dan subjudul sudah terisi. Pengunjung tinggal klik Unduh PNG atau Cetak / PDF.

Buat kode Referensi Catatan
Cara kerja

Tiga langkah, tanpa server

Tidak perlu akun, API key, maupun database. Cukup tempel kode.

  1. Tempel kode

    Salin satu script atau satu link ke halaman website Anda.

  2. Pengunjung klik tombol

    Tools QR terbuka di tab baru dengan form dan pratinjau kartu sudah terisi.

  3. Unduh sendiri

    Pengunjung menekan Unduh PNG atau Cetak / PDF langsung dari halaman Tools.

Referensi

Detail tiap cara pemasangan

Daftar atribut, parameter, dan contoh lengkap.

1

Script tombol otomatis

Cukup satu tag script. Tombol dibuat tepat di bawah tag tersebut.

Link QR memakai alamat halaman saat ini, dan judul kartu memakai judul halaman, kecuali Anda mengisinya lewat atribut.

HTML
<script src="https://konverterqr-khresmupu.netlify.app/assets/js/embed.js"
        data-title="Toko Berkah Jaya"
        data-subtitle="Scan untuk lihat menu"
        defer></script>

Contoh langsung

Tombol di samping dibuat oleh embed.js. Klik untuk membuka Tools dengan form terisi.

Atribut

AtributFungsiBawaan

data-subtitleSubjudul (maks. 120 karakter)Kosong

data-colorWarna pola QR, format d81b60Merah muda
data-bgWarna latar QR, format ffffffPutih

2

Link biasa

Tanpa JavaScript, cocok untuk platform yang membatasi script.

Cukup tag <a> dengan parameter setelah tanda #. Tanda # dipilih karena tidak dikirim ke server sehingga tidak hilang saat hosting melakukan redirect (format ? tetap didukung). Nilai harus di-encode (spasi menjadi %20); builder di atas melakukannya otomatis.

HTML
<a href="https://konverterqr-khresmupu.netlify.app/tools.html#data=https%3A%2F%2Fcontoh.com%2Fmenu&title=Toko%20Berkah%20Jaya&subtitle=Scan%20untuk%20lihat%20menu" target="_blank" rel="noopener">
  Buat QR Code
</a>

Parameter

ParameterFungsiContoh

colorWarna pola QR (hex 6 digit)d81b60

3

Tombol buatan sendiri

Desain tombol mengikuti website Anda.

Tambahkan atribut data-kqr pada tombol, link, atau elemen apa pun. Atribut lainnya sama seperti Cara 1. Muat script dengan data-button="false" agar tidak muncul tombol tambahan.

HTML
<button data-kqr data-url="https://contoh.com/menu" data-title="Toko Berkah Jaya">
  Buat QR Code
</button>

<script src="https://konverterqr-khresmupu.netlify.app/assets/js/embed.js" data-button="false" defer></script>
Catatan penting

Sebelum Anda memasang

Unduh tetap dengan klik

PNG dan PDF diunduh pengunjung sendiri lewat tombol di halaman Tools. Browser memblokir unduhan otomatis tanpa klik.

Platform website

Tempel kode di blok HTML kustom platform Anda (mis. blok “HTML Kustom” di WordPress). Jika script diblokir, pakai Cara 2.

Privasi

Isi QR dikirim ke layanan QR Server saat gambar dibuat. Gunakan untuk link publik, bukan data rahasia.

Gratis tanpa batas

Tanpa API key, tanpa pendaftaran, dan tanpa batas pemakaian. Judul halaman dipakai otomatis bila data-title kosong.
